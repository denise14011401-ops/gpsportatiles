Audios del asistente IA — un archivo .mp3 por producto
========================================================

Coloca aquí los audios generados con ElevenLabs, con estos nombres
EXACTOS (mismo nombre, minúsculas, sin espacios). Cada página de
producto ya está conectada a su archivo correspondiente:

  rastreador-personal-mini.mp3     → Rastreador Personal Mini 4G
  gps-vehicular-oculto.mp3         → GPS Vehicular Oculto OBD-II
  rastreador-mini-tag.mp3          → Rastreador Mini TAG
  gps-moto-antirrobo.mp3           → GPS Antirrobo para Motocicletas MotoGuard
  gps-flotillas-avanzado.mp3       → GPS Avanzado para Flotillas FleetPro
  rastreador-objetos-valor.mp3     → Rastreador Compacto ValueTrack

No hace falta tocar ningún código: en cuanto subas un archivo con
el nombre correcto a esta carpeta, el robot de esa página específica
ya queda funcionando.

Si en algún momento decides usar el MISMO audio en las 6 páginas,
solo copia el mismo .mp3 seis veces con estos seis nombres — es
más simple que editar el código para que todas apunten a un solo
archivo.
